# Dipro Chowdhury — AI/ML & Generative AI Engineer Portfolio

A modern, animated, mobile-first single-page professional portfolio website built with **React**, **Tailwind CSS**, **Framer Motion**, and **Lucide Icons**.

Designed for **Dipro Chowdhury**, showcasing career transition from Quality Engineer at LTIMindtree (LTM) into AI/ML and Generative AI Engineering roles.

---

## ⚡ Tech Stack & Libraries

- **Framework**: [React 19](https://react.dev/) + [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) + Custom Glassmorphism System
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (`whileInView`, scroll-spy transitions, typing headline)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Google Fonts (`Inter`, `JetBrains Mono`, `Outfit`)

---

## 🚀 Quick Start

### 1. Installation
Clone or open the repository folder, then install dependencies:

```bash
npm install
```

### 2. Development Server
Start the local development server:

```bash
npm run dev
```

Open your browser at `http://localhost:3000`.

### 3. Production Build
Build optimized production bundle:

```bash
npm run build
```

Preview production build locally:

```bash
npm run preview
```

## 🌟 Key Features

1. **Dark Tech-Forward Theme**: Slate/charcoal background (`#080c14`), electric cyan/blue accents (`#06b6d4`, `#3b82f6`), and glowing glassmorphism cards.
2. **Interactive AI Background Canvas**: Live neural network particle simulation with connecting vector lines.
3. **Animated Typing Headline**: Dynamic cycling text (*"Quality Engineer"*, *"AI/ML Enthusiast"*, *"Generative AI Developer"*).
4. **Interactive Profile Photo**: Framed headshot with dynamic fit toggle mode (<kbd>↻</kbd> Cover / Contain).
5. **Printable Resume Modal**: One-click printable PDF resume view accessible directly from the Hero section.
6. **Featured AI/ML Projects**:
   - **Malicious URL Detector** (99% Accuracy LSTM Classifier)
   - **EchoGenius AI Voice Assistant** (98% Intent Recognition NLP Engine)
   - **Movie Recommendation System** (TMDB Content-Based Filtering & Cosine Similarity)
7. **Mobile-First Responsive**: Fully optimized across 375px (Mobile Small), 768px (Tablet), 1024px (Desktop), and 1440px (Ultrawide).
